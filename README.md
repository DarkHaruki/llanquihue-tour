# Llanquihue Tour

David Soto — Desarrollo Orientado a Objetos I, Duoc UC Online.

## Semana 4: catálogo de tours

[LlanquihueTourApp](LlanquihueTourApp/) es una aplicación de consola en Java que lee tours desde un archivo de texto y los almacena en un `ArrayList`. Muestra el catálogo, filtra los tours gastronómicos y busca un tour por nombre.

| Carpeta | Contenido |
| --- | --- |
| `LlanquihueTourApp/src/model` | Clase `Tour`: nombre, tipo y precio. |
| `LlanquihueTourApp/src/data` | Lectura del archivo y creación de los objetos. |
| `LlanquihueTourApp/src/ui` | Clase principal `ui.Main`. |
| `LlanquihueTourApp/resources` | Archivo `tours.txt` con seis registros de ejemplo. |

Las [instrucciones de ejecución](LlanquihueTourApp/README.md#ejecución) están en el README del proyecto. Se requiere JDK 8 o superior.
